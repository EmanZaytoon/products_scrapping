# Products Scrapping

A Python desktop application for searching products across Amazon, Jumia, and Noon.

## Features

- Search for products on multiple websites
- Amazon, Jumia, and Noon support
- Scrape product information
- Save results to Excel
- Export product links
- Desktop GUI built with PyQt5
- SeleniumBase for web scraping
- Install the required Python packages:

pip install -r requirements.txt
Run

Run theproducts_scrapping.py Python file of the project.
